# ヨガスケジュールメーカー

ヨガスタジオ・インストラクター向けの、月間スケジュール作成ツールです。
クラスを入力すると、月間カレンダーと Instagram 用の画像が作れます。

## つかいかた

1. スタジオ名と年月を入れる
2. クラス名・講師名を登録する（自分のスタジオのものを自由に）
3. 日付ごとにクラスを追加する（毎週くり返しにも対応）
4. 月間スケジュールを確認する
5. Instagram 用の画像をダウンロードする

## できること

- 日付ごと／毎週くり返しの両方でクラスを登録
- 1週間分をまとめて別の週にコピー
- 午前・午後・夜で高さをそろえた見やすいカレンダー
- 新月・満月を自動で表示（アシュタンガの月の日に）
- クラスがない日は「休み」と表示
- Instagram 用の画像を 4:5 / 1:1 / 9:16 で書き出し
- 印刷・PDF保存
- バックアップの保存と読み込み、直前の状態に戻す機能

## データの取り扱い

入力した内容は**お使いのブラウザの中だけ**に保存されます。
サーバーへの送信は一切ありません（外部通信の処理を持っていません）。
ブラウザのデータを消すと消えるので、大切なものは「バックアップを保存」から
ファイルに書き出しておいてください。

## 動作環境

ブラウザだけで動きます。インストール不要です。
`index.html` をダウンロードしてダブルクリックしても使えます。
