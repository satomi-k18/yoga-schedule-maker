# ヨガスケジュールメーカー

ヨガ教室向けの月間スケジュールと投稿画像を作る、ブラウザだけで動くツールです。

## 完成版 2026-09-10

- 登録・編集／月間スケジュール／投稿画像の3タブ。
- 日付ごと・毎週のクラス登録、週のコピー、編集、元に戻す。
- 5つの配色と、背景・見出し・曜日欄の自由な色指定。
- クラス枠は各クラスに登録した色を使用。
- 月間・週間の投稿画像、印刷・PDF保存。
- 「明日」や指定日のストーリー画像を1080×1920 PNGで保存。
- クラス数と文字量に応じて複数枚に分割。ページを選んで保存。
- 月間画像の日付のないマスもカレンダー本体と同じ背景色。

`index.html` を開いて使えます。投稿画像は保存後、Instagramから手動で投稿します。

## データ

データは利用中のブラウザ内に保存されます。予定JSONはGitHubへ登録しません。
「登録・編集」内のバックアップ機能で保存・読み込みできます。
別URL・別ブラウザに移る場合もバックアップで移行してください。
